# Frequently Asked Questions

## Q: Does SecureLine require a phone number?
A: Currently yes (based on Signal), but we are working on removing this requirement in Phase 2.

## Q: Can the server read my messages?
A: No. All messages are end-to-end encrypted. The server only routes encrypted data.

## Q: Does Tor slow down calls?
A: Yes, Tor adds latency. It is optional and recommended only when privacy is more important than speed.

## Q: Can I self-host my own server?
A: Yes! The server code is open source and can be deployed on any machine.

## Q: Is the app available on iOS?
A: Currently in development. The Android version is available first.

## Q: How do I verify a contact's identity?
A: Compare the security fingerprint (SHA-256 hash of public key) in person or via a trusted channel.

## Q: What happens if I lose my phone?
A: Your messages are encrypted with keys stored in the hardware security chip. Without the device, they are unreadable.

## Q: Can law enforcement access my messages?
A: No. The encryption is designed so that even the server operators cannot decrypt messages.
