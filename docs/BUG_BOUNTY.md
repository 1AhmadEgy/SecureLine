# برنامج مكافآت الثغرات (Bug Bounty Policy) — SecureLine

## 1. نبذة عن البرنامج
ندعو الباحثين في مجال أمن المعلومات لاختبار أمان تطبيق **SecureLine** وخادم التوجيه التابع له. نؤمن بمبدأ الإفصاح المنسق (Coordinated Disclosure) ونكافئ المساهمات التي تحمي خصوصية مستخدمينا.

## 2. النطاق (Scope)

### الأصول المشمولة (In-Scope)
- **تطبيق الأندرويد:** `com.secureline.secureline` (حزم AAB/APK الرسمية).
- **بروتوكول التشفير:** Signal Protocol (X3DH, Double Ratchet), MLS (RFC 9420), وقاعدة بيانات SQLCipher.
- **خادم الإشارات والنقل:** خادم Ktor WebSocket وواجهة برمجة التطبيقات (API).

### خارج النطاق (Out-of-Scope)
- الهجمات التي تتطلب وصولاً مادياً غير مقيّد لجهاز الضحية بعد كسر الحماية (Physical Device Access / Jailbreak).
- الهندسة الاجتماعية (Social Engineering / Phishing).
- هجمات حجب الخدمة (DoS / DDoS).
- ثغرات البرمجيات الأصلية غير المعدلة لمكتبات الطرف الثالث (مثل عيوب عامة في Google WebRTC أو مكتبة Tor دون وجود خطأ في تكوين SecureLine).

## 4. الإبلاغ والإفصاح
- يرجى تقديم التقارير الأمنية عبر البريد المشفر: `security@secureline.app` أو عبر GitHub Security Advisory.
- نلتزم بفترة حظر إفصاح مدتها **90 يوماً** أو حتى إطلاق التحديث التصحيحي، أيهما أقرب.
