# SecureLine 🛡️

**SecureLine** هو تطبيق محادثات ومكالمات (VoIP) فائق الأمان ومفتوح المصدر، مصمم لحماية خصوصية المستخدمين عبر تشفير عسكري، وإخفاء الهوية، وتأمين بيئة التشغيل. يتكون المشروع من تطبيق أندرويد متكامل (Android Client) وخادم توجيه مستقل (Java Server).

---

## ✨ الميزات الرئيسية (Key Features)

### 1. التشفير والخصوصية (Cryptography & Privacy)
* **تشفير مزدوج (Double E2EE):** تعمية البيانات باستخدام دمج بين `AES-256-GCM` و `ChaCha20-Poly1305`.
* **طبقة التعمية (Obfuscation Layer):** إخفاء الهيكل النمطي للبيانات المشفرة لتجاوز أنظمة فحص الحزم العميقة (DPI) وتجاوز الحجب.
* **شبكة تور (Tor Network):** توجيه الاتصالات عبر شبكة Tor لإخفاء عنوان الـ IP الخاص بالمستخدم بالكامل (Anonymity).
* **تبادل المفاتيح الآمن:** باستخدام بروتوكول `X25519` (Diffie-Hellman) مع تناوب المفاتيح.

### 2. المكالمات الآمنة (Secure VoIP)
* مكالمات صوتية مشفرة من طرف إلى طرف باستخدام **WebRTC**.
* تشفير مسار الصوت بالكامل عبر بروتوكول **SRTP**.
* تحكم ذكي بجودة الصوت والتكيف مع سرعة الإنترنت (Adaptive Bitrate).

### 3. تأمين بيئة التشغيل (App Security)
* **SQLCipher:** تشفير قاعدة بيانات الرسائل محلياً على الجهاز.
* **Android Keystore:** تخزين مفاتيح التشفير بشكل آمن في عتاد الهاتف.
* **حماية الشاشة:** منع أخذ لقطات شاشة أو تسجيل فيديو للمحادثات (Anti-Screenshot).
* **مكافحة الهندسة العكسية:** كشف الروت (Root Detection)، ومنع تصحيح الأخطاء (Anti-Debugging).
* **قفل حيوي:** حماية الدخول للتطبيق بالبصمة (Biometric Auth).

### 4. خادم معدوم المعرفة (Zero-Knowledge Server)
* خادم مبني بلغة Java النقية.
* لا يخزن أو يمتلك أي مفاتيح لفك التشفير (الخادم يقوم فقط بتوجيه البيانات المعماة).
* نظام حماية ضد هجمات حجب الخدمة (Rate Limiting & Anti-DDoS).

## 📂 هيكل المشروع (Project Structure)

ينقسم المستودع إلى قسمين رئيسيين:

- 📱 `app/`: كود المصدر الخاص بتطبيق الأندرويد (مبني بـ Java و XML).
- 🖥️ `server/`: كود المصدر الخاص بخادم التوجيه (مبني بـ Java السادة بدون أطر عمل معقدة للسرعة القصوى).

---

## 🚀 كيفية التشغيل (How to Run)

### أولاً: تشغيل الخادم (The Server)
1. قم بفتح مجلد `server/` باستخدام بيئة تطوير مثل **IntelliJ IDEA** أو **Eclipse**.
2. تأكد من تثبيت **JDK 11** أو أحدث.
3. قم بتشغيل الملف `ServerMain.java` الموجود في المسار:
   `server/src/main/java/com/secureline/server/ServerMain.java`
4. سيبدأ الخادم بالعمل على المنفذ `8080`.

### ثانياً: تشغيل تطبيق الأندرويد (The Android Client)
1. قم بفتح مجلد `app/` باستخدام **Android Studio**.
2. **ضبط عنوان الـ IP للخادم:**
   اذهب إلى الملف:
   `app/src/main/java/com/secureline/secureline/network/NetworkConfig.java`
   * إذا كنت ستشغل التطبيق على **محاكي (Emulator)** على نفس جهاز الكمبيوتر، اترك العنوان `10.0.2.2`.
   * إذا كنت ستشغله على **هاتف حقيقي**، قم بتغيير العنوان إلى عنوان الـ IP المحلي لجهاز الكمبيوتر الخاص بك (مثال: `192.168.1.5`).
3. قم بعمل **Build** و **Run** على هاتفك أو المحاكي.
